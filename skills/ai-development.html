02 Experience

AI features with the same engineering discipline as everything else

I treat AI as one component of a system, not the whole of it. The model call sits behind a REST API, inside a tested workflow, with validation on what goes in and care over what comes out.

Document content and user uploads are treated as untrusted, each user gets a private workspace, and answers cite where they came from so people can check them.

The same approach runs through how I build software generally: Claude Code writes much of the code, and I own the design, the security decisions and the review of every change.
